# Барвінкове — повітряна безпека

Статична інформаційна сторінка з посиланнями на публічні джерела та вбудованою офіційною картою повітряних тривог.

## Джерела
- Офіційна карта: https://map.ukrainealarm.com/
- alerts.in.ua: https://alerts.in.ua/
- Харківська ОВА: https://kharkivoda.gov.ua/
- ДСНС України: https://dsns.gov.ua/

## Важливо
Це не офіційна система оповіщення. Зовнішня карта може бути недоступна для вбудовування — у такому разі відкривайте її окремо. Дані можуть надходити із затримкою. Не публікуйте API-токени у файлах сайту: документація alerts.in.ua вказує, що токен є секретним.

## Публікація через GitHub Pages
1. Відкрийте Settings → Pages у репозиторії.
2. У розділі Build and deployment виберіть Deploy from a branch.
3. Виберіть branch `main` і folder `/ (root)`, натисніть Save.
4. Зачекайте, доки GitHub Pages завершить публікацію.
